A good fit for your workflow?

JustSessions is for Mac developers who switch between coding CLIs and return to work across projects or their own SSH machines. Read an existing conversation, then continue in the CLI you already know, in the same app. No Git worktree workflow is required.

Choose Agent Sessions when searching across transcript contents matters most. Choose opcode when you want a Claude Code GUI with custom agents and checkpoints.

JustSessions searches session names, paths, titles, and IDs; reader Find covers loaded messages. SSH requires passwordless access, rsync, and the installed CLI; some providers also need Python 3. With tmux, agent processes can keep running after you quit the app while their machine stays awake.
