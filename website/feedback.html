A little context helps.

Each button opens a draft on GitHub. You need a GitHub account; review your report there before submitting. Reports and replies are public, so remove private code, conversations, credentials, and personal paths from any text or screenshots.

In the Mac app, choose Feedback in the sidebar or Help → Send Feedback… to write your report and optionally include app and macOS versions.
