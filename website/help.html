How it works

Find

Claude Code, Codex, Antigravity, Kiro CLI, OpenCode, and Pi sessions, grouped by host and project.

Read

Click a session to read it. Nothing runs. Find text with ⌘F, or open a window from the reading toolbar.

Resume

Resume continues in the original CLI and folder. Branch tries another approach.

Keep running

Close a tab with Keep running, or quit. Click the session to return to its CLI.

Set up an SSH host

Install tmux on the host so sessions survive a dropped connection or a closed tab. Built-in tmux is only for your Mac.

Required: passwordless SSH, rsync, and the CLI. Antigravity and OpenCode also need python3; Antigravity needs lsof to delete sessions.

Check tmux -V on the host, then choose Add SSH host… in the sidebar.

Also: search, pin, rename, and export sessions as Markdown. Claude Code and Codex on your Mac can notify you when they finish or need input. Features vary by CLI.
