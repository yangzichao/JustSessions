Browse, read, and resume your coding sessions.

Remote hosts over SSH

Install tmux on each remote host. The Mac's bundled tmux only works locally.

Also required: passwordless SSH, rsync, and your CLI. Antigravity needs python3; lsof for deletion.

Check tmux -V on the host, then Add SSH host… with an alias or user@hostname.

Full SSH setup →

What you can do

Claude Code, Codex, Antigravity, Kiro CLI, OpenCode, Pi. Support varies by CLI.

Find sessions

Browse by host and project. Search projects, titles, paths, or IDs.

Read conversations

Preview or choose Read. Find text, adjust size, and copy code.

Resume and start

Resume in the original CLI. Start sessions or project terminals.

Organize and share

Pin, rename, fork, delete, and copy/export Markdown where supported.

Keep work running

With tmux, choose Keep running and reattach later. Plain terminals end when closed.

Make it yours

Settings: themes, appearance, terminal fonts, and local Claude/Codex notifications.
