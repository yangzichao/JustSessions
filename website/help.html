Find, read, and continue your AI coding sessions in one place.

Remote hosts over SSH

Install tmux on the remote host. The app's bundled tmux is only for this Mac. Remote sessions need their own tmux to keep running after a disconnect or closing a tab.

The host also needs passwordless SSH, rsync, and your coding CLI. Antigravity also needs python3; deleting its sessions needs lsof.

Run tmux -V on the host to check installation. Then choose Add SSH host… and enter an SSH config alias or user@hostname.

What you can do

Supports Claude Code, Codex, Antigravity, Kiro CLI, OpenCode, and Pi. Features vary by CLI; see the compatibility guide.

Find sessions

Browse by host and project. Search project names, paths, session titles, or IDs.

Read conversations

Select a session to preview it, or choose Read for a separate window. Find text, adjust its size, and copy code.

Resume and start

Double-click or choose Resume to continue in the original CLI. Start a new session or open a project's Terminal.

Organize and share

Pin or rename sessions, fork supported conversations, copy or export Markdown, and delete old sessions.

Keep work running

With tmux, choose Keep running when closing a tab, then select the session to reattach. Plain terminals end when closed.

Make it yours

Open Settings for themes, appearance, terminal fonts, and local Claude Code or Codex notifications.
