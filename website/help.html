What makes it different

All your CLIs in one place

Claude Code, Codex, Antigravity, Kiro CLI, OpenCode, and Pi, by host and project. It reads the history they already save: no import, no account.

Read without resuming

Preview a session, or open it in its own window from the reading toolbar. Nothing runs until you resume.

Resume where you left off

Continue in the original CLI and project folder, inside the app. Branch to try another approach.

Keep it running

Close a tab with Keep running, or quit the app. Built-in tmux keeps the CLI going; click the session to reattach.

Work on other machines

Resume sessions on SSH hosts. The code and CLI stay on that machine. Set up a host

Set up an SSH host

Install tmux on the host so sessions survive a dropped connection or a closed tab. Built-in tmux is only for your Mac.

Required: passwordless SSH, rsync, and the CLI. Antigravity and OpenCode also need python3; Antigravity needs lsof to delete sessions.

Check tmux -V on the host, then choose Add SSH host… in the sidebar.

Full SSH setup →

Also: search, pin, rename, and export sessions as Markdown. Claude Code and Codex on your Mac can notify you when they finish or need input. Features vary by CLI.
