Install on your Mac

You need macOS 14 Sonoma or later on Apple Silicon, plus an installed CLI with its usual authentication.

  1. Download the signed, notarized JustSessions.dmg.
  2. Open the disk image and drag JustSessions into Applications.
  3. Launch the app. Existing sessions appear under This Mac, grouped by project.

On first launch, a short tour points out your sessions, New session, and SSH hosts beside the controls themselves. Later tips show the first time you need them, such as Resume when you first read a session and tab groups when you first open a tab. Skip any of them, or see the tour and its tips again from Help → Take the Tour.

App updates arrive through Sparkle; check manually in Settings → General. Read the release notes for what changed. JustSessions is free; your CLI provider's charges still apply.

Find and resume a session

  1. Search a project name or path, session title, or session ID.
  2. Select a session to read its conversation preview.
  3. Double-click a session or choose Resume to continue in its original CLI and project folder.

A session whose CLI is already running opens on that process with one click. The + at the top of the sidebar starts an installed CLI, or Terminal for your login shell; a project's + menu offers the same. Switch between Projects to browse saved sessions and Open tabs to switch terminals. Open tabs are grouped by project, with the remote host when applicable. Both views retain their search and scroll position. Time and CLI filters live beside the switch in Projects, with Waiting for you for sessions stopped for your answer or done with a turn you haven't seen; filters do not hide open tabs. Search also matches message text and opens a matching session at that message.

Pin, rename, or export sessions as Markdown. Local Claude Code and Codex sessions can notify you when a turn finishes, and Claude Code also when it needs input.

Read without launching the CLI

The new-window button in the reading toolbar opens the conversation in its own window. Keep it beside your terminal or compare two sessions.

  • Press ⌘F to find text in the loaded messages. Use ⌘G and ⇧⌘G to move between matches.
  • Use A− / A+ to adjust the reading text, the width button to switch between a readable column and the full window width, and the up/down buttons to jump to the first or latest available message.
  • Read formatted Markdown, scroll wide tables and code blocks, and copy code with Copy. Tool calls stay collapsed until you expand them.
  • See images you attached, and screenshots a tool returned, in place for Claude Code, Codex, and Pi, scaled to the reading column.
  • Switch sessions and return to the same reading position while the workspace window stays open. A reading window starts at your current position.
  • Long histories load automatically as you scroll near either end, keeping your position within the message. The reader retains three pages, or a few more when short ones are all in view. Automatic loading pauses while Find is open; the page buttons remain available.

Reading is read-only: it does not start a terminal or change the saved conversation. Positions are kept for the window's lifetime.

Continue on another machine over SSH

Install tmux on the remote host so sessions survive a disconnect or closing a tab. The host also needs passwordless SSH, rsync, and Claude Code, Codex, Antigravity, Kiro CLI, OpenCode, or Pi installed.

Antigravity and OpenCode hosts also need python3; deleting Antigravity sessions needs lsof.

  1. Choose Add SSH host… in the sidebar.
  2. Enter a ~/.ssh/config alias or user@hostname.
  3. Browse the host's projects and resume a session there.

The code and CLI run remotely; supported history is cached on your Mac. JustSessions provides terminal access, not graphical screen sharing.

Detailed SSH setup ↗

Use the native terminal.

Agent sessions and plain shells run in an embedded SwiftTerm AppKit terminal, grouped by project. Choose Open tabs to switch terminals. Under Settings → Appearance → Terminal, choose a color scheme or import your iTerm2 colors.

Work in split view

Right-click another tab and choose New split view with current tab to show two terminals side by side. Keep an agent next to your shell, or compare two sessions. Click either pane to focus it; drag the divider to resize, or double-click it to reverse the views. Each pane has its own close button. Right-click a split tab to separate the views or replace a pane with another tab. Tabs reopen individually after quitting.

Keep work running with tmux

The app includes tmux for this Mac. Direct swift run builds need tmux 3.3+. SSH hosts need their own tmux. Choose Keep running when closing a local tab, then select its session to reattach.

Quitting the app leaves tmux sessions running. Remote tmux sessions survive SSH disconnections. Keep the machine awake; without tmux, closing the tab ends its process. Plain project terminals do not use tmux.

The app's tmux sessions have no prefix key, so every key reaches the CLI. To use your own tmux prefix on an SSH host, point at the host's heading, click its ⋯, and choose Use this host's tmux prefix.

If a session or CLI is missing

  • In Projects, clear the filters, then click the affected host's refresh button.
  • Confirm the CLI runs in your usual terminal. New session menus offer only installed tools.
  • Start one conversation so the CLI creates history. Kiro sessions need a message; archived and subagent OpenCode sessions are excluded.
  • For SSH, check passwordless access, rsync, and the remote CLI. Remote history uses the host's standard Claude Code, Codex, Antigravity, Kiro CLI, and Pi folders, and the OpenCode database its login shell points to.

Your history and accounts

No JustSessions account is required. The app reads CLI files and caches supported SSH history locally; it does not upload conversations to a JustSessions service. Your CLIs still communicate with their providers. Sparkle checks for app updates through a JustSessions update server that counts checks per day and app version, without storing IP addresses or identifiers. After a crash, JustSessions offers to report it with a GitHub issue or an email filled in from the crash report macOS saved; nothing is sent unless you send it.

This website counts page views without cookies or visitor identifiers. Only daily totals by page, source category, country, and device type are saved.

Storage and privacy details ↗

Make it yours.

Open Settings in the sidebar or press ⌘,. Help contains the feature overview and every keyboard shortcut, and the bottom of General has Check for updates and the feedback links. General → Interface language offers Follow System (default), English, or 简体中文. Choose from six themes, including GitHub, Atom One, and Tokyo Night, which color the terminals too, plus light or dark appearance and any monospaced terminal font installed on your Mac, including Nerd Fonts. Under Appearance → Terminal, Colors gives terminals their own color scheme, such as Dracula or Nord, or imports your iTerm2 colors; iTerm2's settings are read only when you choose that. Changes apply in place. Permissions shows whether macOS allows notifications, Full Disk Access, and Local Network.
