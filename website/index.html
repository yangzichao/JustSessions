A few things to know.

Small app. Clear answers.

How do I find an old Claude Code or Codex session?

Open JustSessions to discover the session history already on your Mac. Browse by project or search a project name, path, session title, or session ID. Select a conversation to preview it, then double-click or choose Resume to continue in its original CLI and working directory.

Do I need a new account or subscription?

No. JustSessions is free and open source, with no JustSessions account. Install and sign in to a supported CLI first: claude, codex, or agy. Your AI providers’ own plans, usage limits, and charges still apply.

Where does my conversation history go?

JustSessions reads the files your CLIs already create. It does not upload conversations to a JustSessions service. Adding an SSH host copies supported session files to a local cache over SSH. The CLIs still communicate with their providers, and Sparkle checks GitHub for app updates. Read the storage and privacy guide.

Can I use sessions on another computer?

Yes. Add an SSH host to browse, preview, resume, branch, or start Claude Code and Codex sessions on that machine. The host needs passwordless SSH access, rsync, and the relevant CLI. This is terminal access; JustSessions does not provide graphical remote desktop control.

Will my session keep running when I close the app?

With tmux available when the session launches, it can. Install tmux 3.3+ locally, or tmux on the SSH host, and choose Keep running when closing a local terminal tab. Keep the host awake and running. Without tmux, closing the terminal tab ends its process.

Which Macs are supported, and how do updates work?

JustSessions requires macOS 14 Sonoma or later on Apple Silicon. Download the Developer ID signed, Apple-notarized disk image and drag the app into Applications. Subsequent app updates are delivered through Sparkle. Browse release notes.
